# DSA Interview Preparation

A pattern-wise Data Structures and Algorithms learning journey in Java, focused on product-based software engineering interviews.

## Learning workflow

For every pattern:
1. Understand the pattern and when to recognize it.
2. Study a representative LeetCode problem.
3. Derive brute force, better (when useful), and optimal approaches.
4. Document Java implementations, dry runs, and complexity.
5. Solve related problems independently.
6. Review mistakes and revisit problems before advancing.

## Repository conventions

- Use Java for solutions.
- Use descriptive problem names and include the LeetCode number.
- Keep brute-force and optimized implementations clearly identified.
- Include time complexity, auxiliary space complexity, and important edge cases.
- Commit your own implementations and notes.
